# AUTOKLINIK 3D CAMERA — тест QR
iPhone-приложение для проверки распознавания восьми QR-кодов камерой. Накопительно показывает, какие коды уже встречались в кадре. Не измеряет геометрию.

## Значения QR
AUTOKLINIK-3D-1 ... AUTOKLINIK-3D-8 (строго с этими строками).

## Codemagic
Codemagic автоматически прочитает `codemagic.yaml`. Workflow `ios-marker-test` выполняет unsigned simulator build для проверки компиляции. Для IPA на физический iPhone требуется Apple Developer signing, отдельный device archive/export workflow. Этот YAML сам по себе IPA не создаёт.

## Маркеры
Распечатайте восемь QR с указанными значениями. Камера должна увидеть каждый хотя бы раз; цифра останется отмеченной до нажатия «Сбросить результаты». Это не проверка одновременной видимости или точности измерений.
